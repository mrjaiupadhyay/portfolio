## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/mrjaiupadhyay/portfolio.git
```

Navigate to the project:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

## ☁️ Deployment

This portfolio is deployed using **Vercel**.

### Production Build

```bash
npm run build
```

### Deployment

The project can be deployed by connecting the GitHub repository to Vercel or by using the Vercel CLI.
